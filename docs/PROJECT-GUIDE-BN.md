## ১ · এই প্রজেক্টটা আসলে কী

এটা **ছোট ছোট টেক্সট ফাইল দিয়ে বানানো একটা ওয়েবসাইট**। কোনো ডেটাবেজ নেই, সাইট

## ২ · যে শব্দগুলো বারবার শুনবেন

| শব্দ | আপনার জন্য এর মানে |
|---|---|
| **React** | যে সিস্টেম ছোট ছোট ব্লক দিয়ে পেজ বানায় |
| **Component** | একটা ব্লক। একটা `.jsx` ফাইল। হেডার একটা কম্পোনেন্ট, ফুটার আরেকটা |
| **JSX** | `.jsx` ফাইলের ভেতরের ভাষা — HTML আর JavaScript একসাথে |
| **Vite** | কাজ করার সময় সাইট চালায়, আর পাবলিশের সময় প্যাকেজ করে |
| **Tailwind** | স্টাইল ছোট ছোট শব্দে লেখা: `text-white`, `mt-[20px]` |
| **GSAP** | অ্যানিমেশন লাইব্রেরি — স্ক্রলে যা কিছু নড়ে |
| **Lenis** | স্ক্রলটা মসৃণ করে, ঝাঁকি ছাড়া |
| **Build** | সোর্স ফাইল থেকে রেডি `dist/` ফোল্ডার বানানো |
| **Deploy** | `dist/` ইন্টারনেটে তুলে দেওয়া |
| **Repo** | আপনার প্রজেক্ট ফোল্ডার, পুরো হিস্ট্রিসহ, GitHub-এ রাখা |
| **Commit** | সেই হিস্ট্রির একটা সেভ পয়েন্ট। যেকোনো সময় ফিরে যাওয়া যায় |

## ৩ · ফোল্ডার ম্যাপ

```

│

│
├── src/                  ← সাইট আঁকার সব কোড
│   ├── main.jsx          ← সবার আগে যে ফাইলটা চলে
│   ├── App.jsx           ← কোন পেজ দেখাবে সেটা ঠিক করে

│   │

│   ├── lib/              ← ছোট হেল্পার (রাউটিং, SEO, অ্যাকসেস কোড)
│   ├── hooks/            ← বারবার ব্যবহারযোগ্য আচরণ
│   └── data/             ← /content-কে পেজের বোধগম্য রূপে বদলায়
│
├── content/              ← আপনার লেখা। আপনি বা /admin এডিট করে
│   ├── settings.json     ← অ্যাকসেস কোড, কনট্যাক্ট ইমেইল
│   └── case-studies/     ← প্রতি কেস স্টাডির একটা .json

├── public/               ← যা হুবহু কপি হয়ে সাইটে যায়
│   ├── assets/           ← সব ছবি
│   ├── fonts/            ← ফন্ট

├── scripts/              ← বিল্ডের সময় নিজে থেকে চলে
├── docs/                 ← এই গাইড, CMS গাইড, প্রেজেন্টেশন
└── dist/                 ← তৈরি হওয়া সাইট (হাতে এডিট করবেন না)
```

## ৪ · একটা পেজ কীভাবে স্ক্রিনে আসে

```
কেউ rahat-uxd.vercel.app/about খুলল
        ↓
index.html লোড হলো (খালি খোলস)
        ↓
main.jsx চলল
        ↓
App.jsx ঠিকানা দেখল: "/about"
        ↓
App.jsx AboutPage.jsx দেখাল
        ↓
AboutPage.jsx ফাইলের উপরের constant থেকে লেখা নিল
        ↓
GSAP স্ক্রল অ্যানিমেশন শুরু করল
```

`App.jsx` বোঝা দরকার, কারণ এটাই সুইচবোর্ড। সহজ ভাষায় এটা বলে:

> ঠিকানা `/about` হলে About পেজ দেখাও।
> কেস স্টাডি হলে আর এখনো লক থাকলে লিস্টের উপর কোড বক্স দেখাও।
> কেস স্টাডি আনলক থাকলে কেস স্টাডি দেখাও।
> `/case-studies` হলে লিস্ট দেখাও।
> নাহলে হোমপেজ — মানে Hero, About, Logos, CaseStudy, AngleMarque, Footer একটার পর একটা।

হোমপেজের সেকশনগুলো এই ক্রমেই দেখায় এই কারণে। ক্রম বদলাতে চাইলে `App.jsx`-এর
ওই লাইনগুলোর ক্রম বদলাবেন।

## ৫ · ঠিকানা (রাউটিং)

`src/lib/router.js` — নিজেদের বানানো ছোট রাউটার, প্রায় ৮৮ লাইন।

আগে `#about` স্টাইলের ঠিকানা ছিল। সেগুলো আসল পাথে (`/about`) বদলানো হয়েছে,
কারণ `#`-এর পরের অংশ Google আর লিংক প্রিভিউ দেখতে পায় না — ফলে প্রতিটা পেজ
নিজেকে হোমপেজ বলে পরিচয় দিচ্ছিল। পুরনো `#` লিংক এখনো কাজ করে, নিজে থেকেই
নতুন ঠিকানায় বদলে যায়।

**আপনার জন্য এর মানে:** এখন প্রতিটা পেজের নিজস্ব টাইটেল, নিজস্ব বর্ণনা, আর শেয়ার
করলে নিজস্ব প্রিভিউ কার্ড আছে। এটা `src/lib/seo.js`-এ হয়, আর লাইভ ডোমেইনটাও
শুধু ওখানেই এক জায়গায় লেখা:

```js
export const SITE_URL = "https://rahat-uxd.vercel.app";
```

ডোমেইন বদলালে শুধু ওইটুকু বদলাবেন, বাকি সব নিজে থেকে ঠিক হয়ে যাবে।

## ৬ · আপনার লেখা কোথায় থাকে

এই প্রজেক্টে **দুই ধরনের লেখা** আছে। কোনটা কোন ধরনের সেটা জানলে অনেক
বিভ্রান্তি বাঁচে।

**ধরন ১ — কম্পোনেন্ট ফাইলের ভেতরের লেখা।** পেজের হেডিং, গল্পের প্যারা, চাকরির
তালিকা। এগুলো ফাইলের উপরের দিকে পরিষ্কার নামের constant-এ থাকে:

```js
const STORY_INTRO = [
  "I studied Computer Science and gave code an honest run…",
  "Design did — I was the kid who made our football club's logo…",
];
```

কোটেশন চিহ্নের **ভেতরের** লেখা বদলাবেন। বন্ধনী, `const`, সেমিকোলন — এগুলোতে হাত
দেবেন না। পুরো তালিকা: [CONTENT-GUIDE.md](../CONTENT-GUIDE.md)।

**ধরন ২ — কেস স্টাডির কনটেন্ট।** এটা কোডের **বাইরে**, JSON হিসেবে
`content/case-studies/`-এ থাকে। প্রতি স্টাডির একটা ফাইল। `/admin` এগুলোই এডিট করে।

আলাদা রাখার কারণ: কেস স্টাডি ঘন ঘন বদলায়, আর এগুলোই ব্রাউজার থেকে কোড এডিটর না
খুলে বদলাতে চাইবেন। পেজের হেডিং প্রায় কখনোই বদলায় না।

## ৭ · `/admin` এডিটর

![CMS লগইন](screenshots/05-admin-cms.png)
*`/admin` — Decap CMS, GitHub দিয়ে লগইন*

`/admin` থেকে পাবলিশ করলে যা হয়:

```
আপনি Publish চাপলেন
   ↓
Decap GitHub-এ content/case-studies/-এ একটা JSON লিখল
   ↓
সেটাই একটা commit — হিস্ট্রির একটা সেভ পয়েন্ট
   ↓
Vercel টের পেয়ে আবার বিল্ড করল
   ↓
প্রায় দুই মিনিট পর লাইভ
```

তাই CMS আলাদা কোনো সিস্টেম নয়, নিজের ডেটাবেজও নেই। আপনি হাতে যে ফাইলগুলো এডিট
করতে পারতেন, ও সেগুলোই এডিট করে। সেটআপ আর ব্যবহার: [CMS.md](CMS.md)।

> **নোট:** শেষে স্ল্যাশ ছাড়া `/admin` খুললে আগে ভেঙে যেত — ভুল ঠিকানায় কনফিগ
> ফাইল খুঁজত আর YAML এরর দেখাত। `public/admin/index.html`-এ কনফিগের পুরো ঠিকানা
> বসিয়ে ঠিক করা হয়েছে। কখনো *"Error loading the CMS configuration"* দেখলে ওই
> জায়গাটাই দেখবেন।

## ৮ · কেস স্টাডির অ্যাকসেস কোড

কেস স্টাডিগুলো ক্লায়েন্টের কাজ, তাই ৪ ডিজিটের কোডের পেছনে রাখা — পাবলিক সার্চে
আসে না।

- কোডটা `content/settings.json`-এ (`"accessCode": "1453"`), `/admin` → Settings
  থেকেও বদলানো যায়
- একটা স্টাডি আনলক করলে **শুধু সেটাই** খোলে; অন্যটা আবার কোড চাইবে
- আনলক ৩০ মিনিট থাকে (`accessMinutes`), তারপর আবার চায়
- ব্রাউজারে মনে রাখে, প্রতি স্টাডির জন্য আলাদাভাবে

**এটা কী, সেটা নিয়ে সৎ থাকুন:** এটা ভদ্রতার দরজা, নিরাপত্তা নয়। সাধারণ
ভিজিটরের সার্চ থেকে ক্লায়েন্টের কাজ আড়ালে রাখে। কেউ জেদ ধরলে পার হতে পারবে।
`src/lib/caseAccess.js`-এর কমেন্টেও ঠিক এটাই লেখা আছে।

ডিটেইল পেজগুলোতে `noindex` দেওয়া, তাই সার্চ ইঞ্জিন এড়িয়ে যায় — পাবলিক পেজগুলো
স্বাভাবিকভাবেই ইনডেক্স হয়।

## ৯ · ডেস্কটপ, ট্যাব আর মোবাইল

সাইটটা প্রথমে ফিক্সড ১৪৪০px-এ বানানো ছিল। এখন সব সাইজে মানিয়ে নেয়। তিনটা
কৌশলে কাজটা হয়:

**১ · ফ্লুইড টাইপ।** টাইপ সাইজ ফিক্সড সংখ্যা নয়, একটা রেঞ্জ — তাই ব্রেকপয়েন্টে
লাফ না দিয়ে মসৃণভাবে ছোট হয়। `src/index.css`-এ:

```css
--text-display: clamp(38px, 5.9vw, 84px);
```

পড়বেন এভাবে: ৩৮px-এর কম কখনো নয়, ৮৪px-এর বেশি কখনো নয়, মাঝখানে উইন্ডোর সাথে
বদলাবে।

**২ · এক ফাইলে দুই লেআউট।** Tailwind-এর প্রিফিক্স ঠিক করে দেয় কোনটা কখন:
`max-lg:` মানে ১০২৪px-এর নিচে, `lg:` মানে ১০২৪px আর তার উপরে। তাই এক
কম্পোনেন্টেই দুই ভার্সন থাকে — এজন্যই আলাদা কোনো মোবাইল কোডবেজ নেই যেটা আলাদা
করে মেইনটেইন করতে হবে।

**৩ · সাইজভেদে আলাদা অ্যানিমেশন।** GSAP-এর `matchMedia` ফোনে অন্য অ্যানিমেশন
চালায়। হোমপেজের কেস স্টাডি রেল ডেস্কটপে পিন হয়ে পাশে চলে; ফোনে সেই একই কার্ড
উপর-নিচে সাজে আর ফেড-ইন করে। টাচ স্ক্রিনে পিন করা পাশের স্ক্রল খারাপ অভিজ্ঞতা,
তাই ওখানে ব্যবহার করা হয়নি।

## ১০ · কাজের রেসিপি

### নিজের মেশিনে সাইট চালানো

```bash
npm run dev
```

তারপর `http://localhost:5173` খুলবেন। ফাইল সেভ করলেই ব্রাউজার নিজে আপডেট হয়।
বন্ধ করতে `Ctrl+C`।

### লোকালে এডিটর চালানো

```bash
npm run cms
```

`npm run dev` চালু রেখে দ্বিতীয় একটা টার্মিনালে। তারপর
`http://localhost:5173/admin`।

### রেডি সাইট বানানো

```bash
npm run build
```

`dist/` তৈরি হয়। প্রতিটা পেজ বানানোর সময় নাম দেখাবে। **এই কমান্ড ফেইল করলে
পাবলিশ করবেন না** — কিছু একটা ভাঙা।

### কোনো লেখা বদলানো

১. [CONTENT-GUIDE.md](../CONTENT-GUIDE.md)-এ খুঁজে বের করুন
২. ফাইল খুলে কোটেশনের ভেতরের লেখা বদলান
৩. সেভ করে ব্রাউজারে দেখুন
৪. commit করুন

### নতুন কেস স্টাডি

`/admin` ব্যবহার করুন — এটা এজন্যই বানানো। হাতে করতে চাইলে
`content/case-studies/`-এ পুরনো একটার গঠন কপি করে নতুন `.json` বানাবেন। ছবি
যাবে `public/assets/`-এ; ছবির মাপ বিল্ডের সময় `scripts/image-sizes.mjs` নিজে
মেপে নেয়, আপনাকে হাতে লিখতে হয় না।

### অ্যাকসেস কোড বদলানো

`/admin` → Settings। অথবা সরাসরি `content/settings.json`।

### লাইভ ডোমেইন বদলানো

`src/lib/seo.js`-এর `SITE_URL`। এক জায়গা।

### কাজ সেভ করা

```bash
git add -A
git commit -m "কী বদলেছেন লিখুন"
git push
```

Vercel নিজে থেকে রিবিল্ড করে। প্রায় দুই মিনিটে লাইভ।

## ১১ · কিছু ভেঙে গেলে

**সবচেয়ে বড় ভরসা: সবসময় পেছনে ফেরা যায়।** প্রতিটা commit একেকটা সেভ পয়েন্ট।

| যা দেখছেন | সম্ভাব্য কারণ |
|---|---|
| পুরো সাদা পেজ | `.jsx` ফাইলে টাইপো — একটা `"` বা `,` মিসিং |
| লেখায় `${...}` দেখাচ্ছে | টেমপ্লেট স্ট্রিংয়ের ব্যাকটিক/ব্র্যাকেট নষ্ট |
| পেজ আসে কিন্তু এক সেকশন নেই | অ্যানিমেশন এরর — কনসোল দেখুন |
| `npm run build` ফেইল | শেষ কয়েক লাইন পড়ুন, ফাইল আর লাইন নম্বর লেখা থাকে |
| "Error loading the CMS configuration" | `/admin` কনফিগ পাথ — সেকশন ৭ দেখুন |
| সব ভেঙে গেছে | `git checkout .` — সেভ না করা সব পরিবর্তন ফেলে দেয় |

এরর দেখতে: Chrome-এ সাইট খুলে ডান-ক্লিক → Inspect → Console ট্যাব। লাল লেখাটাই
এরর। কপি করে রাখবেন — ওতে ফাইলের নাম আর লাইন নম্বর থাকে।

**`dist/` কখনো এডিট করবেন না।** প্রতি বিল্ডে ওটা নতুন করে বানানো হয়, আপনার
পরিবর্তন মুছে যাবে।

## ১২ · আরও কিছু জানার মতো

- **`dist/` আর `node_modules/` আপনার কাজ নয়।** দুটোই তৈরি হওয়া জিনিস। মুছে গেলে
  `npm install` আর `npm run build` দিলে ফিরে আসে।
- **`.gitignore`** ফাইলে লেখা থাকে Git কোনগুলো ইচ্ছে করে অগ্রাহ্য করবে — পুরনো
  ডুপ্লিকেট `Rahat-Portfolio/` ফোল্ডারটাও ওখানে আছে।
- **`api/auth.js` আর `api/callback.js`** — এই দুটো ছোট ফাংশন CMS-কে GitHub দিয়ে
  লগইন করতে দেয়। শুধু Vercel-এ চলে।
- **`scripts/prerender.mjs`** প্রতি বিল্ডের পর প্রতিটা পেজের জন্য আসল HTML ফাইল
  লেখে, সাথে `robots.txt` আর `sitemap.xml`। এজন্যই প্রতিটা পেজ আলাদাভাবে লিংক
  করা আর খুঁজে পাওয়া যায়।
- **কোডের কমেন্টগুলো আপনার জন্যই লেখা।** বেশিরভাগ ফাইলের শুরুতে একটা ব্লক আছে
  যেখানে ফাইলটা কী আর কেন এভাবে বানানো তা বলা। পড়ার মতো — ডেভেলপার নন এমন
  কারও জন্যই লেখা হয়েছে।
